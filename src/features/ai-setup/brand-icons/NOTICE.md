# Brand icons

These icons come from [@thesvg/icons](https://github.com/glincker/thesvg) 4.0.4, where each logo's license is listed. All logos are trademarks of their owners.

Six logos were simplified to render in one color: `groq`, `kimi`, `litellm-proxy`, `microsoft-azure`, `llama-cpp-server`, and `cohere`.

Four logos are not in that package, so they were recreated from each project's own artwork:

| Icon      | Source                                  | How it was made                                |
| --------- | --------------------------------------- | ---------------------------------------------- |
| `bifrost` | `bifrost-logo.png` in `maximhq/bifrost` | Rebuilt from measured pixels                   |
| `jan`     | `logo-mark.svg` in `janhq/jan`          | Traced from the embedded bitmap                |
| `9router` | `favicon.svg` in `decolua/9router`      | Converted the "9" to outlines using Inter Bold |
| `portkey` | Portkey's GitHub avatar                 | Redrawn by hand                                |
